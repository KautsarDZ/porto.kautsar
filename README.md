# Portfolio Starter

A responsive, one-page portfolio starter built with Vite, React, TypeScript, Tailwind CSS v4, Framer Motion, and Lucide icons.

## Requirements

Node.js 20+ and npm.

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
```

`npm run dev` starts the local development server. `npm run build` writes the production-ready static site to `dist/`.

## Customise content

Edit `src/data/portfolio.ts` to replace the placeholder name, biography, skills, projects, experience, email, and social links. The page renders its content from that single file.
